How papers get here. Every weekday a job queries arXiv across the categories and phrases listed in config/settings.yaml, drops anything that fails an engineering-relevance gate, and sorts the rest into the SEIKM topic areas using the weighted phrase lists in config/topics.yaml. Nothing is hand-picked, and nothing is peer-reviewed by this site — inclusion is not endorsement.

Topic definitions follow the SEIKM 2027 track proposal. To correct a mis-filed paper or widen a topic, edit config/topics.yaml and open a pull request — no code changes needed.
